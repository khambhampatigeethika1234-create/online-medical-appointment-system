# Online Medical Appointment System

## About the Project

The Online Medical Appointment System is a web-based application designed to make doctor appointment booking easier and more convenient for patients.

Patients can register, login, view doctors, book appointments, make payments, receive appointment receipts, use video consultation and chat features.

## Features

- Patient Registration and Login
- Doctor Information and Availability
- Online Appointment Booking
- Doctor Selection
- Payment System
- Payment Receipt
- Video Consultation
- Chat With Us
- Patient Dashboard
- Patient Profile Management
- Edit Profile
- Change Password
- My Appointments
- Admin Login
- Admin Dashboard
- Patient Management
- Doctor Management
- Appointment Management
- Payment Records
- Appointment Status Management

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Main Modules

### Patient Module
Patients can register, login, manage their profile, book appointments, view appointments and access online consultation features.

### Doctor Module
The system displays doctor information including specialization, experience, availability and ratings.

### Payment Module
Patients can complete the appointment payment process and view their payment receipt.

### Admin Module
The administrator can manage patients, doctors, appointments and payment records.

## Project Purpose

The main purpose of this project is to provide a simple online platform for patients to book and manage medical appointments and for administrators to manage the appointment system.
